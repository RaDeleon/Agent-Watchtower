# Claude Watchtower 0.8.0

The first tagged release of Claude Watchtower, a local, passive observer of Claude Code, Codex and Hermes usage. It contains everything built through Stage 8. Nothing sits in the request path: hooks, the status line and read-only adapters write to a local SQLite database, and every page reads from it.

**Capture and accounting.** Claude Code hooks and status-line snapshots record activity. Transcript ingestion records exact per-request token counts, deduplicated by request. Active hours come from an event-gap model rather than wall-clock session spans. Rollups add per-project and per-model history, cost at API prices beside Claude Code's own figure, response times and turn waits. Every hook call is best-effort, so a tracker failure never breaks Claude Code.

**Sources.** Codex rollouts and Hermes's state database sit beside Claude, each with hours, an API-price estimate for Codex, Hermes's own reported cost, and a level. OpenViking contributes a health probe and Atlas a checkpoint link to Claude sessions.

**Dashboard.** `watchtower` serves Overview, Live, History, Projects, Sessions, Models & Skills, Usage Profile (ten disciplines), Performance, Character, Quests, Codex, Hermes and Sources from a zero-dependency Node server bound to loopback. `watchtower report` writes the historical pages to one static HTML file.

**Progression.** Each tool levels on an OSRS-style curve to 99. Its projects, models and Claude Code skills (grouped into packs) level as sub-skills, with pace, streaks and a level-up log. Weekly habit quests target your three weakest Usage Profile disciplines. Tiered achievements are dated to the day you reached them. Quest and Achievement Points stay outside the Total level.

Requires macOS or Linux with `bash`, `jq` and the `sqlite3` CLI, and Node.js 22.18 or newer with default TypeScript stripping. Install from source as the README describes. The database is at schema v10, and later versions migrate it in place. This is a preview: measurements and page layouts may still change between minor versions.
