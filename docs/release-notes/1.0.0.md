# Agent Watchtower 1.0.0

The first public release. Watchtower watches Claude Code, Codex and Hermes, so it is now **Agent Watchtower**: repository `Agent-Watchtower`, release archive `agent-watchtower-<version>.tar.gz`. The features are those of 0.10.0, and the database schema is unchanged (`CC_SCHEMA_VERSION` 11, `WT_SCHEMA_VERSION` 3).

**Open source.** Watchtower is licensed under the Apache License 2.0 (`LICENSE`).

**A new repository.** This repository's history starts at 1.0.0. The 0.x releases were developed and published in a private repository, now archived. Their notes stay in `docs/release-notes/` and their rows in the release history.

**What keeps its name.** The `watchtower` CLI, the `claude_*` tables, the files installed under `~/.claude` and the database path are unchanged. They hold Claude Code's own data, and renaming them would be a migration with no benefit. An existing install keeps working: clone this repository and run `bash capture/install.sh`, or `./bin/watchtower setup`, to update it.

**Releases.** `npm run release` runs `gh` as the account that owns `origin`, whichever account is active, and titles the release without "(preview)". Development dependencies are TypeScript 7 and Vitest 5.

**Versions.** From 1.0.0 on, a major version marks a change that breaks an existing install's data or a documented command, a minor version adds features, and a patch fixes them.

Requires macOS or Linux with `bash`, `jq` and the `sqlite3` CLI, and Node.js 22.18 or newer with default TypeScript stripping.
